# 数据提供方路由

只调用当前环境里真实存在的能力。每次使用其他 Skill 前，先读取其 `SKILL.md`，遵守其限流、格式和核验要求。

## 任务到提供方

| 任务 | 首选 | 补充 | 关键限制 |
|---|---|---|---|
| A 股行情、K 线、资金、公告、研报、龙虎榜、涨停池 | `a-stock-data` | 交易所、巨潮官方页 | 东财端点必须遵守其限流规则 |
| 中国及全球新闻宽扫描 | `news-aggregator-skill` | TrendRadar、RSSHub、自定义 OPML | Reuters fallback 是 Google News 聚合，需保留标签 |
| 最新官方政策、媒体原文、查漏 | `agent-reach` | 浏览器或公开 API | 最新信息必须联网；优先官方域名 |
| 国际快讯、加密、宏观突发 | OpenNews MCP（若已配置） | Reuters、央行和交易所原文 | 第三方聚合结果不能替代官方确认 |
| 金十快讯、经济日历、商品外汇 | Jin10 MCP（若已配置） | 官方数据发布日历 | 需要 Token；快讯是线索和解读来源 |
| 全球证券身份、行情、新闻、财务、期权 | Yahoo Finance/yfmcp（若已配置） | 公司 IR、交易所申报 | 核对代码后缀、交易所和币种 |
| 历史新闻、去重、趋势和推送 | TrendRadar（若已配置） | 本 Skill 的标准化脚本 | 覆盖取决于订阅源配置 |
| 巨潮、雪球及动态网页转 RSS | ForgeRSS（若已配置） | RSSHub | 网页结构变化可能造成抓取失效 |
| 大量网站转 RSS | RSSHub（若已配置） | 官方 RSS 或网页 | 自建实例更可控；注意 AGPL |

## 环境降级顺序

1. 有官方 API、RSS、公告或统计发布页：直接使用。
2. 有本机 Skill 或已配置 MCP：调用并保留原始字段。
3. 没有专用接口：用 `agent-reach` 搜索官方域名和一线媒体。
4. 只有二手报道：将状态标为“媒体报道”或“待核实”。
5. 来源不可访问：报告缺口，不用模型记忆补造当天新闻。

## 典型扫描组合

### 全球早报

- `news-aggregator-skill`：国际新闻、华尔街见闻、Reuters fallback。
- `a-stock-data`：A 股公告、市场热点、资金和重大异动。
- `agent-reach`：央行、统计数据、监管和重大公司的官方原文。
- 可选 OpenNews/TrendRadar/Jin10：扩充快讯、历史检索和日历。

### 指定证券

- 先确认代码、交易所、币种和证券类型。
- A 股优先 `a-stock-data`；海外证券可用 yfmcp 或公开市场数据。
- 财报、融资、并购、诉讼、处罚和管理层变动回到公司 IR、交易所或监管文件。
- 再用新闻聚合源补充市场解释和分析师观点。

### 突发事件

- 先找最早可信来源和事件发生时间。
- 至少寻找一个官方来源和一个独立媒体来源；官方尚未确认时不要强行满足数量。
- 检查相关资产当时是否处于交易时段，再描述市场反应。
