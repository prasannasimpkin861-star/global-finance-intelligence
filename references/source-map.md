# 国内外核心财经来源地图

这是一份核验清单，不代表每次都要逐项访问。根据时间窗口、市场和事件类别选择相关来源；网站入口和访问规则可能变化，使用前应联网确认。

## 中国内地：官方与一手来源

### 宏观、财政、货币与监管

- 中国政府网：国务院政策、常务会议和重要文件。
- 中国人民银行：货币政策、公开市场操作、金融统计、社融和发布会。
- 国家发展改革委：产业、价格、投资和能源政策。
- 财政部：财政收支、国债、税收和政府采购。
- 国家统计局：GDP、CPI、PPI、PMI、工业、消费、投资和就业。
- 中国证监会：资本市场政策、行政处罚、发行审核和监管问答。
- 国家金融监督管理总局：银行、保险和非银金融监管。
- 国家外汇管理局：跨境资金、外汇储备和国际收支。
- 海关总署：进出口和贸易数据。
- 商务部：外贸、外资、消费和制裁反制信息。
- 工业和信息化部：制造业、通信、汽车和产业政策。
- 国家能源局：电力、煤炭、油气和新能源数据。

### 证券、期货与公司公告

- 上海证券交易所、深圳证券交易所、北京证券交易所。
- 巨潮资讯：沪深北上市公司法定信息披露。
- 中国证券登记结算有限责任公司。
- 中国金融期货交易所、上海期货交易所、大连商品交易所、郑州商品交易所、广州期货交易所、上海国际能源交易中心。
- 中国银行间市场交易商协会、中央国债登记结算、上海清算所、全国银行间同业拆借中心。

## 香港

- 香港交易所披露易：上市公司公告和权益披露。
- 香港证券及期货事务监察委员会。
- 香港金融管理局。
- 香港政府统计处和财经事务及库务局。
- 上市公司投资者关系网站。

## 美国

- Federal Reserve：FOMC、会议纪要、讲话、资产负债表和统计数据。
- U.S. Treasury：财政、国债发行、制裁和国际资本流动。
- BLS：CPI、PPI、就业和工资。
- BEA：GDP、PCE、个人收入和国际收支。
- SEC/EDGAR：10-K、10-Q、8-K、Form 4、13D/13G、13F 和发行文件。
- CFTC：期货监管和持仓报告。
- OCC、FDIC、FINRA、FTC、DOJ：银行、券商、竞争和执法信息。
- EIA：原油、天然气、电力和库存。
- 公司 IR 与交易所公告：NYSE、Nasdaq、CME、ICE。

## 按事件类别选源

| 事件 | 必查一手源 | 常用补充 |
|---|---|---|
| 央行决议 | 央行声明、纪要、讲话 | Reuters、Bloomberg、FT |
| 宏观数据 | 统计机构原始发布 | 一线媒体、经济日历 |
| 中国资本市场政策 | 证监会、交易所、国务院部门 | 新华社、主流财经媒体 |
| 公司财报 | 交易所申报、公司 IR | 电话会、媒体和研报 |
| 并购融资 | 公司公告、监管文件 | Reuters、行业媒体 |
| 商品供给冲击 | 政府、企业、交易所、EIA/IEA/OPEC | 商品专业媒体 |
| 制裁与地缘事件 | 政府公告、国际组织 | Reuters、AP、BBC |
| 加密监管与上币 | 监管机构、交易所公告、链上记录 | 专业加密媒体 |
| 市场异动 | 交易所行情、可靠报价 | 同期快讯、公告、资金数据 |
