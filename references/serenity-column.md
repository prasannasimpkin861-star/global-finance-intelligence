# Serenity 专栏：最近 24 小时 X 帖子分析

财经早报、晚报和每日全市场扫描必须包含本专栏。当前固定观察对象为 **Serenity / `@aleabitoreddit`**，主页为 `https://x.com/aleabitoreddit`。账号可能改名或被仿冒，因此每次采集都要核对显示名、简介、自我链接和历史帖子连续性；不得因为名称相似而换用其他账号。

## 时间窗口

- 默认窗口为 `(截稿时间 - 24 小时, 截稿时间]`，以截稿时区计算；中文日报通常使用北京时间。
- 保留 X 原始 UTC 时间并转换成北京时间，正文使用明确日期和时分。
- 分页读取直到出现早于窗口起点的帖子。若受接口上限、登录、限流、删除、私密或搜索索引限制影响，必须报告实际抓取数量、最早覆盖时间和缺口，不能声称“全部帖子”。
- 如果窗口内没有可确认的新帖，专栏仍保留，写明“最近 24 小时未检索到可确认的新帖”及数据源状态，不用旧帖填充。

## 采集顺序

先读取并遵循 `agent-reach` 的 X/Twitter 路由：

1. 运行 `agent-reach doctor --json`，确认当前可用后端。
2. 有完整显式凭据时，优先使用 `twitter user-posts @aleabitoreddit -n 100`；凭据只放在子进程环境，禁止打印 Cookie、`TWITTER_AUTH_TOKEN` 或 `TWITTER_CT0`。
3. twitter-cli 不可用时，可使用用户已经登录并明确控制的 OpenCLI 浏览器会话。
4. 再用公开网页搜索、X 帖子索引站或媒体引用补缺。这些只能作为发现线索；能取得原始 X 链接时必须回到原帖核对。
5. 对高影响帖子，至少再核对一个公司公告、监管文件、财报、产业数据或一线媒体来源。无法核实时明确写“Serenity 观点/自述，外部事实尚未核验”。

采集范围包括原创帖、长帖/Article 分享、带本人评论的引用帖和含实质观点的回复。纯转发、点赞、无信息量玩笑、重复庆祝、表情回复不进入逐条分析，但计入抓取覆盖说明。连续 thread 合并成一个事件，保留所有相关原帖链接。

## 真实性与来源分层

- 原始 X 链接只能证明“该账号发布了这段内容”。
- 帖子里的财务数字、客户关系、订单、供应链映射、产品进度和宏观判断，仍需外部来源核验。
- 自述持仓、收益率、成交截图和期权回报统一标注“作者自述，未独立核验”。没有明确披露时不得推断其持仓。
- 将帖子中的内容区分为：`可核事实`、`供应链推断`、`主观判断`、`价格预测`、`持仓/业绩自述`。
- Serenity 属于社交媒体分析来源。其帖在“作者观点”层面是一手材料，但不能替代公司、监管机构、交易所或统计机构的一手事实。

## 筛选与权重

优先分析：

- 新增或撤回的股票观点；明确加仓、减仓、退出或反转，但只在作者明说时记录。
- AI、半导体、存储、光通信/CPO、先进封装、数据中心电力、Neocloud、机器人等供应链变化。
- 新客户、订单、产能、认证、价格、交付、资本开支、融资、稀释和现金流线索。
- 对已有观点的关键证实、反证、失效条件或时间表变化。
- 可能引起个股或细分行业明显波动的长帖、图表和引用资料。

普通闲聊、重复观点和缺少新增信息的回帖可以合并到“其他动态”。不能按点赞、转发或粉丝数直接判断观点正确性。

## 固定输出格式

### Serenity 专栏｜最近 24 小时

开头先写：

- **监测窗口**：起止时间和时区。
- **抓取状态**：完整 / 部分；共检索多少条，纳入分析多少条；使用了什么后端；已知缺口。
- **一句话概括**：当天主要主题，以及与此前观点相比是否发生变化。

然后按重要性列出帖子。每条至少包括：

1. **北京时间｜帖子类型｜原帖链接**
2. **他说了什么**：忠实概括，不替作者补结论。
3. **涉及标的与主题**：美股代码、海外公司、A/H 股映射和产业链位置；无法可靠映射时不硬贴股票。
4. **观点变化**：新观点 / 加强 / 延续 / 降低 / 反转 / 暂不明确。
5. **证据核验**：已核实的外部事实、未核实的推断及来源等级。
6. **市场影响卡**：
   - 大盘：A 股 / 港股 / 美股分别为偏利好、偏利空、分化或影响有限；
   - 风格：成长/价值、大盘/小盘、周期/防御；
   - 受益与承压行业；
   - 传导路径；
   - 已发生反应或预期影响；
   - 时间窗口、置信度和成立条件。
7. **主要风险**：估值、流动性、小市值波动、客户集中、稀释、技术验证、消息真实性及观点失效条件。

专栏末尾给出两个汇总：

- **24 小时观点变化表**：标的/主题｜变化方向｜主要依据｜置信度。
- **A/H 股映射表**：海外事件｜可能相关的一级/二级行业｜传导依据｜直接或间接｜风险。映射必须基于业务关系或共同产业变量，不能只因名称相近或同属热门概念就建立联系。

## 表述边界

- 不把 Serenity 的帖子写成买卖指令，不使用“跟买”“抄作业”“必涨”等措辞。
- 小盘股和低流动性标的要单独提示波动、滑点、稀释和信息不对称风险。
- 帖子发布在休市期间时写“预期影响，尚待开盘验证”，不能声称已经带动股价。
- 如果市场在帖子发布前已经异动，不能倒因为果；应说明帖子可能只是强化关注度。
- 引用原文只保留必要短句，正文以概括和核验为主。
